# 🌌 STROPHE 28: AUTONOMOUS SKILL FORGE (ROUTER)

This is the **Self-Reflective Cortex** of the Seraphic OS. It allows the agent to expand its own mind. When a task is "too hard" or lacks a dedicated silo, the agent is commanded to **Forge a new Skill**.

### 🏛️ THE DECISION MATRIX
Before forging, the agent must ask:
1.  **Is this a Macro-Skill?** (e.g., A multi-domain strategic workflow).
2.  **Is this a Sub-Skill?** (e.g., A specific functional routine like "OAuth Auth").
3.  **Is this an Atomic-Skill?** (e.g., a low-level patch or a tool-specific fix).
