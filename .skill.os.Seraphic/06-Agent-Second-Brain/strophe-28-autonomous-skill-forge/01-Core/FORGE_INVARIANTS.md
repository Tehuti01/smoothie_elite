# 🌀 FORGE INVARIANTS (CORE)

Strophe 28 governs the **Recursive Inception** of the Matrix. It treat knowledge as a dynamically expanding code repository.

## 🌀 THE PRINCIPLES OF AUTONOMOUS INCEPTION

### I. The "Too Hard" Trigger
- **Mandate:** If a problem requires more than 10 turns of reasoning or if the same logic is repeated 3 times, the agent must ask: "Should I forge a skill for this?"
- **Rule:** If the answer is YES, the agent must immediately execute `auto_forge.py`.

### II. Taxonomy Resolution (The 3 Scales)
1.  **Macro-Skills:** Broad knowledge silos (e.g., "Sovereign UI"). These require a new Category in `manifest.json`.
2.  **Sub-Skills:** Specific functional silos within a category (e.g., "SDF Shadows").
3.  **Atomic-Skills:** Micro-fixes or tool patches. These are typically added to an existing skill's `04-Commands`.

### III. The Code-Trigger Mandate
- **Law:** A skill is dead without a code trigger.
- **Requirement:** Every forged skill must include a Rust or Python command that "checks itself."
- **Logic:** The command asks: "Does the current codebase need this skill?" If yes, it prints the skill's location.
