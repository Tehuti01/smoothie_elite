# 🔮 MATERIAL DSL (CORE)

The **Smoothie UI Language** allows developers to describe the physical properties of their interface using high-level Rust enums.

## 🌀 THE THREE RECURSIVE MATERIALS

### I. Seraphic Metal (`Material::BrushedMetal`)
- **Physics:** Anisotropic light scattering using high-frequency noise kernels.
- **Law:** Reflection vectors MUST follow the tangential grooves of the circular SDF.
- **Goal:** Emulate the look of brushed aluminum or anodized steel found on $5,000 hardware synths.

### II. Abyssal Glass (`Material::FrostedGlass`)
- **Physics:** Multi-pass Gaussian blur on the backdrop with chromatic aberration.
- **Law:** Light refraction index must be PHI-resonant (`IOR = 1.618`).
- **Goal:** Create immersive frosted overlays with physical depth.

### III. Valeon Radiance (`Material::Radiance`)
- **Physics:** Exponential light decay following the inverse square law.
- **Law:** `Glow = Strength * exp(-distance * PHI)`.
- **Goal:** Realistic LEDs, oscilloscope beams, and spectral visualizers.
