# Seraphic OS: System Manual

## 1. File Structure and Categorization
The entire `.skill.os.Seraphic` directory is heavily categorized with a 3-layer depth structure (Category -> Subcategory -> Sub-Subcategory -> Sub-Sub-Subcategory -> Skill File) to ensure total organization.

### Identifiers
- Directories: Prefixed with `f-<id>-<tag>` (e.g., `f-01-secbrain`).
- Files: Prefixed with `fi-<id>-<tag>` (e.g., `fi-101-prompt-template.md`).

## 2. Global Categories
The OS is divided into the following primary skill categories:

1. **f-01-secbrain (Second Brain)**: Agent protocols, LLM instructions, prompt design, and autonomous workflows.
2. **f-02-math (Mathematics & Physics)**: Astrophysics, geometry, spatial logic, celestial constants.
3. **f-03-frontend (Frontend & UI)**: React, Holographic UI, advanced interface design.
4. **f-04-backend (Backend & APIs)**: NodeJS, routing, distributed AI models.
5. **f-05-sysarch (System Architecture)**: Rust, memory allocation, atomics, crate orchestration.
6. **f-06-dsp (DSP & Audio)**: Spectral mastering, SIMD optimizations, latency management.
7. **f-07-testing (Testing & QA)**: Multi-faceted testing, test validation invariants.
8. **f-08-security (Security & Integrity)**: Cryptography, authentication, system mandates.
9. **f-09-tools (Tools & Frameworks)**: TS tool building, skill creators, forging logic.
10. **f-10-devops (DevOps & CI)**: Workflows, deployments, automation pipelines.
11. **f-11-coreos (Core OS)**: Seraphic prime logic, core manifest files.
12. **f-12-meta (Meta & Scripts)**: Ouroboros forever loops, matrix generators.

## 3. Skill Anatomy
Every skill file begins with a template block (id and category) followed by the intro and content, making it easily parsed. The skills provide distinct functions (e.g., how to build an atomic weaver, how to manage context loops).
