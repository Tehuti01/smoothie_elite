# 🧠 SKILL ANATOMY v0.2.0 (CORE)

Strophe 13 governs the **Skill Creator**. In the 12x pass, we treat AI skills as **Neural Executables**. A skill is not just text; it is a precisely tuned prompt-kernel designed to achieve 300 IQ sub-agent performance with minimal token friction.

## 🌀 THE RECURSIVE INVARIANTS (12X DEPTH)

### I. The Token Sanctuary Law
- **Quantum Goal:** Maximum information density per token.
- **Law of Redundancy:** Re-stating system-prompt facts is a terminal violation. Every instruction must provide *new* procedural knowledge that the agent does not already possess.
- **Goal:** Minimize context-window pressure to maximize reasoning "juice."

### II. Agentic Ergonomics
- **Quantum Goal:** Zero friction between the skill and the agent's tool-use logic.
- **Law of Triggers:** A skill must have a "Sovereign Trigger"—a YAML description so precise that the agent's attention-mechanism is drawn to it with 100% accuracy during relevant tasks.
- **Path:** Use precise technical keywords and explicit "Trigger when..." clauses.

### III. The Recursive Knowledge Loop
- **Quantum Goal:** Skills that improve themselves based on usage metrics.
- **Law of Evolution:** Every skill must include an `evals/` set to benchmark its own accuracy.
- **Path:** We utilize the Ouroboros Loop from Strophe 14 to audit skill performance.
