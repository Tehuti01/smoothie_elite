# DSP Modules

The `smoothie-dsp` crate contains the mathematical primitives required to build complex audio algorithms.

## 1. Filters

Smoothie Elite ships with two primary filter topologies.

### BiquadFilter (Direct-Form II Transposed)
The standard workhorse for EQs and simple filtering. It is highly optimized but can artifact when parameters are modulated at audio rates.
- **Types:** LowPass, HighPass, BandPass, Notch, AllPass, Peaking, LowShelf, HighShelf.

### ZdfFilter (Zero-Delay Feedback)
The "Elite" choice. This topology preserves the analog structure of the filter in the digital domain.
- **Why use ZDF?** It handles extreme audio-rate modulation (like an envelope sweeping a cutoff) flawlessly, with zero artifacts.
- It sounds inherently more "analog" due to instantaneous feedback resolution.

## 2. Oscillators

Wavetable and algorithmic oscillators for synthesis.
- **Wavetable Oscillator:** Uses 2048-sample tables with high-order interpolation to prevent high-frequency aliasing.
- **PolyBLEP:** Generates mathematically perfect Saw, Square, and Triangle waves by mathematically subtracting the aliasing artifacts generated by digital steps.

## 3. Oversampling

When applying non-linear distortion (saturation, clipping, wavefolding), harmonics are generated that can exceed the Nyquist frequency, reflecting back down into the audible spectrum as harsh, atonal noise (Aliasing).

```rust
use smoothie_dsp::oversampling::Oversample2x;

let mut os = Oversample2x::new(max_block_size);

os.process(&mut block, |upsampled_buffer| {
    // Run distortion here at 88.2kHz / 96kHz
    apply_hard_clip(upsampled_buffer);
});
```
The oversampler uses a steep Polyphase Halfband FIR filter to cleanly upsample, and then cleanly downsample back to the host rate.

## 4. The Math Library

Located in `smoothie-math`. Standard library math functions (`f32::sin()`) are too slow for DSP.
- `fast_sin()`, `fast_cos()`, `fast_tanh()` utilize polynomial approximations.
- Decibel conversions: `linear_to_db()`, `db_to_linear()`.
- Pitch conversions: `midi_to_hz()`, `hz_to_midi()`.
