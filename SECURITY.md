# Security Policy

## Supported Versions

Only the current LTS release is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

To report a vulnerability, please email `security@seraphic-technologies.dev` or use the GitHub Security Advisory feature.
